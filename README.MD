
# 🤖 Yashwanth | Ollama Streamlit AI App

A simple Generative AI application built using **Python, Streamlit, Ollama, and DeepSeek R1**.

## 🚀 Features

- User-friendly Streamlit interface
- Runs an LLM locally using Ollama
- Uses DeepSeek R1 1.5B
- Accepts user prompts
- Generates AI responses in real time

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- DeepSeek R1 1.5B
